# AutoBell – The Smartest Cloud-Based Bell Management System

This document provides a comprehensive overview of **AutoBell** from a marketing perspective, including its features, functionality, and materials for promotional activities (brochures and video ads).

---

## 🚀 Product Overview & Value Proposition

**AutoBell** is a next-generation, cloud-managed SaaS platform designed for schools, colleges, and madrasas. It automates daily schedules, provides instant emergency alerts, and allows for custom audio broadcasts—all controlled via a sleek **Web Dashboard** and a powerful **Mobile App**.

### Core Values:
- **Automation:** Set your entire academic year's schedule in minutes.
- **Reliability:** Local cache ensures bells ring even if the internet is down.
- **Flexibility:** Switch between "Exam Mode," "Normal Day," or "Ramadan" profiles with one tap.
- **Safety:** Instant lockdown and emergency triggers from any authorized smartphone.
- **Support:** Optional yearly backup device service for zero downtime.

---

## 🛠️ Key Features & Functionality

### 1. Smart Bell Hardware (IOT Device)
- **WiFi Connectivity:** Easy setup via a built-in access point (WiFi Manager).
- **Industrial Stability:** ESP32-based controller for 24/7 operation.
- **Local Intelligence:** Stores schedules locally to function offline.
- **Precision Timing:** Syncs with NTP servers for second-level accuracy.
- **High-Quality Audio:** Supports MP3 playback via amplifiers/speakers.

### 2. Web Admin Dashboard (The Control Center)
- **Multi-Tenant SaaS:** Separate environments for every school/campus.
- **Role-Based Access:** Super Admin, School Admin, and Operator levels.
- **Profile Management:** Create unlimited profiles (e.g., Summer, Winter, Exams).
- **Audio Manager:** Upload, preview, and manage custom MP3s for bells and announcements.
- **Real-Time Monitoring:** Check device status (online/offline) and health logs.
- **Broadcast Module:** Send one-off announcements or voice notes instantly.
- **Branding:** Customize the dashboard with your school's logo and color theme.
- **Backup & Restore:** Full system backup capabilities (database, schedules, logs, and MP3 media).

### 3. Mobile App (Control in Your Pocket)
- **On-the-Go Management:** Change active profiles from anywhere.
- **Manual Trigger:** Ring any bell sound immediately with a single tap.
- **Emergency Mode:** High-priority "Lockdown" or "Alarm" buttons.
- **Live Status:** Monitor all devices and their last heartbeats.
- **Broadcast:** Send voice announcements directly from your phone's microphone.

### 4. Advanced Cloud Capabilities
- **Text-to-Speech (TTS):** Generate professional announcements by just typing text.
- **OTA Updates:** Securely update device firmware over-the-air with new features.
- **Automated Logging:** Tracks every ring and system event for audit trails.
- **Secure Backend:** Powered by Supabase with Row Level Security (RLS).
- **Hardware Watchdog:** Auto-recovery system ensuring 100% hardware uptime without manual restarts.
